## Website 2: https://developer.mozilla.org
1. Find the navigation menu - what tag is it wrapped in?
   - The main navigation is wrapped in a <nav> element (semantic navigation).
2. How is the search bar structured?
   - The search is typically a <form> containing an <input type="search"> and a <button> (or input type="submit"). It may include ARIA roles/labels and live suggestions.
3. What happens when you hover over links (check the styles)?
   - On hover, link styles typically change color and may get an underline or other visual affordance; the specific CSS (color change, text-decoration) is applied from stylesheet rules.
